# Odin Recipes

A basic recipe website I’m building as part of The Odin Project’s Foundations course. It will include a homepage linking to three recipe pages, each with an image, a description, ingredients, and preparation steps.

## Project Goals

The goal is to practice HTML and become more comfortable building a website from scratch. I’ll focus on organizing the content and connecting the pages, with CSS styling to come later.

## Skills I’m Practicing

- Setting up the basic structure of an HTML document
- Using headings and paragraphs
- Adding images with descriptive alt text
- Creating ordered and unordered lists
- Linking pages using relative paths
- Organizing project files and folders
- Using Git and GitHub to track my progress

- Git and GitHub
